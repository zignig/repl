# Replica of blobstore.

SO ... I had a pretty big blobs store of random stuff mostly uploaded with [sendme](https://www.iroh.computer/sendme). I had a pretty large stash of random files from a number of devices. It was cool, I could access all my files from a single place and it was fast and content based.

... AND then my SSD popped. and the entire blob store was gone.

I have written this to use [iroh-smol-kv](https://github.com/n0-computer/iroh-smol-kv) with [blobs](https://github.com/n0-computer/iroh-blobs) and [gossip](https://github.com/n0-computer/iroh-gossip) to make a (terrible) replica of all the blobs that you have onto another [Endpoint](https://docs.iroh.computer/concepts/endpoints#endpoints).

It works... YAY and I have three copies of _most_ of the data that I lost.
